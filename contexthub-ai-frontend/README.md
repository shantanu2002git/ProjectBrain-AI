# ContextHub AI Frontend

Next.js, React, TypeScript, Tailwind CSS, shadcn-style components, React Flow, and Monaco Editor shell for the ContextHub AI MVP.

## Getting Started

```bash
npm install
cp .env.example .env.local
npm run dev
```

The app runs on `http://localhost:3000` and expects the backend at `http://localhost:4000`.
In Vercel, API requests use the same-origin `/api` path, which is routed to the backend service.
